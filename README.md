# Does increasing family income disrupt the intergenerational transmission of psychopathology?

## Overview

This repository contains the R analysis scripts accompanying the study *Does increasing family income disrupt the intergenerational transmission of psychopathology?*

The study examines whether unconditional cash transfers moderate associations between maternal depressive symptoms and offspring psychopathology, using data from two longitudinal studies: the **Great Smoky Mountains Study (GSMS)** and **Baby's First Years (BFY)**.

## Repository contents

| Script | Description |
|---|---|
| `01_gsms_data_preparation_imputation.R` | GSMS data preparation and multiple imputation |
| `02_gsms_main_analyses.R` | GSMS primary analyses |
| `03_gsms_additional_analyses.R` | GSMS additional and sensitivity analyses |
| `04_gsms_three_generation_analyses.R` | GSMS exploratory analyses across three generations |
| `05_gsms_late30s_analyses.R` | GSMS supplementary analyses of psychiatric outcomes in the late 30s |
| `06_bfy_analyses.R` | BFY primary, sensitivity, and exploratory analyses |

## Data availability

The datasets are not included in this repository. Researchers wishing to reproduce the analyses must obtain access to the relevant GSMS and BFY data through the appropriate data access procedures.

## Reproducing the analyses

The scripts are written in R and require access to the relevant datasets.

A local `config.R` file defining the `gsms_dir` directory path is required. This file is not included because it contains local configuration information.

The GSMS scripts should be run in numerical order. The BFY analysis script can be run separately, although the combined exploratory results table requires an output generated by the GSMS analyses.
